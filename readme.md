## 🔍 نظرة عامة

مشروع **Google Apps Script** مصمم لمحاكاة استجابات **80 طالب** على اختبار
**Google Forms** من نوع MCQ (اختيار من متعدد)، مع تطبيق **قبلي وبعدي**
يحقق **دلالة إحصائية** عند مستوى `p < 0.005`.

### 🎯 الغرض

مساعدة الباحثين في مجال التعليم على:
- محاكاة بيانات بحثية واقعية لاختبارات قبلية/بعدية
- ضمان وجود فروق ذات دلالة إحصائية
- توزيع الاستجابات زمنياً بشكل طبيعي وواقعي
- تحليل النتائج حسب المهارات الفرعية

|--------|-------|

| **تحسن مرتبط** | الطلاب الأضعف يتحسنون أكثر (Regression to Mean) |

📐 النموذج الإحصائي
نموذج احتمال الإجابة الصحيحة
text

P(correct) = Base + SkillEffect + Noise - Fatigue

حيث:
  Base        = 0.25 (احتمال التخمين لـ 4 اختيارات)
  SkillEffect = 0.70 × Skill × (1 - Difficulty × 0.5)
  Noise       = random × (1 - Consistency) × 0.25
  Fatigue     = FatigueRate × (Q - 20) / 10  [للأسئلة > 20]

الحدود: 0.08 ≤ P ≤ 0.96
نموذج توليد الطلاب
text

Pre-Test:
  PreSkill ~ N(μ=0.45, σ=0.14)
  الحدود: [0.15, 0.80]

Improvement:
  Base = 0.27
  WeakBonus = (μ_pre - PreSkill) × 0.5
  Improvement ~ N(μ=Base×(1+WeakBonus), σ=0.08)
  الحدود: [0.05, 0.45]

Post-Test:
  PostSkill = PreSkill + Improvement
  الحدود: [0.35, 0.95]
التحقق الإحصائي
text

Paired t-test:
  t = M_diff / (SD_diff / √n)

  المطلوب: t > 2.89 → p < 0.005
  المتوقع: t ≈ 12-18 → p < 0.0001 ✅

Effect Sizes:
  Cohen's d = M_diff / SD_pooled
  المتوقع: d ≈ 1.2-1.8 (كبير جداً) ✅

  η² = t² / (t² + df)
  المتوقع: η² ≈ 0.65-0.80 ✅
