# ساب بلان 4 — مرحلة تطوير المحتوى الإلكتروني

## الحالة: لم يُكتب بعد

## المرجع في نموذج خميس (2015)
1. المقدمة | 2. المتن | 3. الخاتمة

---

## المهام المطلوبة — بالتفصيل

### تكت 4.1 — وصف المقدمة في البيئة
فقرة تصف ما يراه الطالب عند الدخول لأول مرة:
- شاشة الترحيب + عنوان البحث + اسم الباحث + شعار الجامعة
- التعليمات العامة + قائمة المحتويات + شروط التعلم
- رابط الاختبار القبلي

### تكت 4.2 — وصف تطبيق الأدوات القبلية على المنصة
- اختبار مهارات حل المشكلات القبلي عبر Google Forms
- مقياس التدفق الذهني القبلي عبر Google Forms
- إجابة إلزامية قبل الوصول للمحتوى

### تكت 4.3 — وصف عرض الأهداف
صفحة في بداية كل وحدة بالأهداف السلوكية (نموذج ABCD)

### تكت 4.4 — تطوير النصوص التعليمية
- المحتوى من الكتاب المدرسي (مقرر الفلسفة — الصف الأول الثانوي — الوحدة الأولى)
- تقسيم لدروس قصيرة + أمثلة + عرض على محكمين

### تكت 4.5 — تطوير أنشطة حشد المصادر
فقرتان لكل مجموعة تشرح كيف بُني النشاط على Google Classroom:
- **م1 (تنافسي+مفتوح):** Assignment فردي → كل طالب يرفع ملفه → لا deadline
- **م2 (تنافسي+محدد):** Assignment فردي → كل طالب يرفع ملفه → deadline محدد
- **م3 (تشاركي+مفتوح):** Assignment مشترك → Docs مشترك → لا deadline
- **م4 (تشاركي+محدد):** Assignment مشترك → Docs مشترك → deadline محدد

### تكت 4.6 — إعداد الوسائط المتعددة
فقرة لكل نوع وسيط: فيديوهات + إنفوجرافيك + صور + نصوص

### تكت 4.7 — وصف الخاتمة
ملخص كل وحدة + تدريبات ذاتية (5-7 أسئلة) + رابط الاختبار البعدي + مراجع

### تكت 4.8 — وصف تطوير مقياس التدفق الذهني (2-3 صفحات)

1. **الهدف:** قياس مستوى التدفق الذهني لطلاب الصف الأول الثانوي أثناء دراسة الفلسفة
2. **الأساس النظري — نموذج أباظة (2011) — 8 أبعاد:**
   1. إدارة الوقت بإيجابية والشعور بالمسؤولية
   2. تحديد الأهداف بدقة
   3. مستوى النشاط العالي والعمل الجاد
   4. الاندماج الكامل في العمل
   5. تركيز الانتباه ومواجهة التحديات بثقة
   6. نسيان الذات والزمان والمكان
   7. الشعور بالمتعة والدافعية
   8. الأداء التلقائي مع القدرة على اتخاذ القرارات
3. **صياغة العبارات:** عدد لكل بُعد + ليكرت خماسي
4. **عرض على المحكمين:** تخصصاتهم + نسبة الاتفاق + التعديلات
5. **الصدق:** محتوى + اتساق داخلي
6. **الثبات:** ألفا كرونباخ (≥ 0.70)
7. **الصورة النهائية:** عدد العبارات + طريقة التصحيح + الدرجة القصوى

### تكت 4.9 — وصف تطوير اختبار مهارات حل المشكلات (3-4 صفحات)

> **ملاحظة مهمة:** اسم الأداة "اختبار مهارات حل المشكلات" وليس "اختبار تحصيلي"

1. **الهدف:** قياس مهارات حل المشكلات الفلسفية لدى طلاب الصف الأول الثانوي
2. **المهارات المقاسة** (بناءً على تحليل المهمات):
   - تحديد المشكلة الفلسفية وتوضيحها
   - جمع المعلومات والمصادر ذات الصلة
   - صياغة الفروض والحلول المحتملة
   - اختيار الحل الأنسب وتبريره
   - تقويم الحل في ضوء المعايير الفلسفية
3. **جدول المواصفات:** توزيع الأسئلة على:
   - الموضوعات (وحدة 1 + وحدة 2)
   - مهارات حل المشكلات (5 مهارات أعلاه)
   - عدد الأسئلة لكل خلية
4. **نوع الأسئلة:** مواقف فلسفية تتطلب حل مشكلات (اختيار من متعدد 4 بدائل / أسئلة مقالية قصيرة)
5. **عرض على المحكمين:** جدول قبل/بعد التعديل
6. **التجربة الاستطلاعية:** (تفاصيل في ساب بلان 5)
7. **تحليل المفردات:** سهولة + صعوبة + تمييز
8. **الصدق والثبات:** (تفاصيل في ساب بلان 5)
9. **زمن الاختبار:** (أول + آخر) ÷ 2
10. **الصورة النهائية:** عدد الأسئلة + الدرجة القصوى + الزمن

### تكت 4.10 — لقطات شاشة من البيئة
بعد بناء البيئة فعلاً — 6-8 لقطات على الأقل
