## المهام المتبقية — بالتفصيل

### تكت 3.0 — تصحيح سطر 71 (أولوية قصوى!)
**المطلوب:** تغيير "المجموعة التجريبية الأولى: نمط حشد المصادر (التشاركي) + زمنه (المفتوح)" إلى "المجموعة التجريبية الأولى: نمط حشد المصادر (**التنافسي**) + زمنه (**المفتوح**)"

### تكت 3.1 — كتابة سيناريو م1: تنافسي + مفتوح

**المطلوب (7 خطوات إجرائية):**
1. **الدخول + الاختبار القبلي**: الطالب يفتح Google Classroom → الشاشة الرئيسية → التعليمات → اختبار مهارات حل المشكلات القبلي + مقياس التدفق الذهني
2. **عرض الأهداف**: أهداف الوحدة الأولى
3. **عرض المحتوى — الوحدة الأولى**: نصوص + فيديو + صور عن "الفلسفة والأخلاق البيئية والبيوطبية"
4. **نشاط حشد المصادر التنافسي المفتوح (الجوهر)**:
   - كل طالب يحصل على نفس المشكلة الفلسفية كاملة
   - كل طالب يبحث فردياً عن مصادر ويقدم حله الخاص
   - لا يوجد حد زمني — الطالب ينهي متى يشاء
   - تُقوّم كل الحلول → يُحدد أفضل حل → الفائز
   - التحفيز: مسابقة + ترتيب الأفضل
5. **ملخص + تقويم بنائي**
6. **تكرار للوحدة الثانية** "الأخلاق المهنية ودور القيم"
7. **الاختبار البعدي**: اختبار مهارات حل المشكلات + مقياس التدفق الذهني

### تكت 3.2 — سيناريو م2: تنافسي + محدد
- مثل م1 لكن **مع مؤقت زمني** لكل مهمة
- كل طالب فردياً + deadline + مسابقة
- ضغط الوقت يزيد المنافسة

### تكت 3.3 — سيناريو م3: تشاركي + مفتوح
**الاختلاف الجوهري عن م1:**
- الطلاب يُقسمون إلى **مجموعات** (4-5 طلاب)
- المشكلة تُقسم إلى أجزاء → كل طالب يبحث عن مصادر لجزئه
- تجميع المكونات الفرعية في حل واحد متكامل
- **بدون حد زمني**
- التحفيز: تعاون + ذكاء جمعي

### تكت 3.4 — سيناريو م4: تشاركي + محدد
- مثل م3 (مجموعات تتعاون) لكن **مع مؤقت زمني**
- ضغط وقت + تعاون = سرعة اتخاذ قرار مشترك
